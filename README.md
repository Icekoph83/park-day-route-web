# Park Day Route (web app test)

A test copy of a personal Walt Disney World day planner, published with GitHub Pages so it can use the phone's
location and try opening the My Disney Experience app. Unofficial; not affiliated with Disney.

No trip data is stored here. A trip is loaded on the phone with a copy-and-paste code from the planner and stays on that phone.
Wait times come from ThemeParks.wiki.
